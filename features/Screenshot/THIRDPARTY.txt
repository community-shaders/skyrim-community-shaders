HDR AVIF dependency notices
===========================

Scope: the Windows x64 static build selected by vcpkg.json, using libavif's
AOM encoder. The applicable upstream copyright notices, complete license
terms, and patent grants follow below.

libavif 1.4.1: library license and the additional notice for src/obu.c.
https://github.com/AOMediaCodec/libavif/tree/v1.4.1

libaom 3.13.1 (vcpkg port revision 1): library, fastfeat, vector, x86inc,
and the enabled SVT-AV1 convolution code. The AOM Patent License 1.0 applies
to libaom and that SVT-AV1 code; its text is included once below.
https://aomedia.googlesource.com/aom/+/d772e334cc724105040382a977ebb10dfd393293/

libyuv 1916: conversion/scaling code referenced by libavif.
https://chromium.googlesource.com/libyuv/libyuv/+/d98915a654d3564e4802a0004add46221c4e4348/

Build recipes and patches:
https://github.com/microsoft/vcpkg/tree/dddca6fa87f177e0678e2545c4b4636a44aa05bd/ports

The selected build excludes libavif's apps/iccjpeg, GDK plugin and Android
wrapper, and libaom's Highway code. JPEG archive members are not referenced
by the screenshot encoder's static-library dependency closure. Their notices
and optional author lists are omitted. Recheck this scope if dependencies,
build options, or the encoding/conversion calls change.

# Advanced Skin 皮肤制作指南

在功能设置里启用 Advanced Skin 后，它会立刻用**公用皮肤参数**作用于所有兼容的皮肤。只有当某套皮肤需要和公用参数不一样，或者你为它画了专用贴图时，才需要看下面的内容。

本文描述的是当前分支的实现。它可以编译通过，但还没有在游戏里完整验证过；遇到不符合预期的表现，请当作可能的 bug 反馈。

英文版：[advanced-skin-artist-guide.md](advanced-skin-artist-guide.md)。技术细节：[advanced-skin-materials.md](advanced-skin-materials.md)。

## 只有一条规则

**材质属于皮肤贴图。** 不属于模型，不属于衣服，也不属于角色。

每一张皮肤漫反射贴图旁边，都可以放一个小文件：

```
textures/actors/character/female/femalebody_1.dds          <- 你的皮肤贴图
textures/actors/character/female/femalebody_1.csskin.json  <- 它的材质
```

所有显示这张贴图的地方，都使用这个材质：

- 使用这套皮肤的所有角色和 NPC。
- 护甲和衣服里露出来的手臂、腿、腰腹。游戏会把穿戴者的皮肤贴图贴到这些部位上，所以它们会自动和裸体保持一致。你永远不需要为每件衣服单独设置材质。
- 第一人称的手臂。

反过来，显示另一张贴图的地方就使用另一个材质。虎人和人类可能共用同一个身体模型，但贴图不同，所以材质各自独立。主角换了种族，头部显示的贴图变了，就会自动换成那张贴图的材质。

你不需要修改模型，不需要 ESP，也不需要知道某件衣服用的是哪个模型。

## 在游戏里制作材质

打开 **CS 编辑器 → 皮肤编辑器**。页面的用法和场景管理器一样：左边是列表，右边是正在编辑的内容，上方的面包屑告诉你修改会写到哪一层。

1. 点击**玩家**；或者先在控制台里点选一个 NPC，再点击**控制台所选对象**。
2. 左栏按头部、身体、双手、双脚分组，列出角色显示的每一张皮肤贴图。名字下面写着它出现在哪里，包括衣服和第一人称。前面的圆点表示材质状态：绿色表示有材质文件；蓝色表示本次刚保存；红色表示文件有错误、已被忽略；空心表示只用公用参数。选中一张贴图。
3. 控件上方的面包屑是 **公用 › 贴图材质 › 整个角色 › 角色在此贴图上**。高亮的是**贴图材质**：你正在编辑所有显示这张贴图的对象共用的材质。
4. 选择一个类别（**贴图**、**双层高光**、**绒毛与边缘**、**透射与 SSS**、**细节法线**、**湿润响应**），然后修改数值。修改一个数值就会把它设置在当前层，前面的方框会自动勾上并变绿。取消勾选，或右键选择**恢复继承**，就回到公用参数。鼠标悬停在名字上，可以看到这个数值来自哪一层。
5. 观察效果。编辑器打开期间，草稿会显示在**所有使用这张贴图的对象**上，包括其他已加载的角色，和保存之后的效果完全一致。水滴按钮可以测试固定的湿润程度。
6. 用磁盘按钮或 **Ctrl+S** 保存。面包屑下面一行写着文件保存到哪里：游戏 Data 目录下、贴图的旁边（用 Mod Organizer 时会落在 Overwrite 里）。点**更换文件夹**可以改为写进你自己的 mod；这个选择会被记住，贴图工具也会写到那里。

面包屑旁的工具栏还有**撤销**/**重做**、**还原**到已保存的文件、**复制与分享**和**清空此层**。面包屑里某一层后面、或列表里某张贴图上有圆点，表示有未保存的修改。有未保存的修改时切换贴图，会先询问。

每一行贴图输入都有一个文件夹按钮，它浏览的是游戏看到的 Data 文件夹（用 Mod Organizer 时就是所有 mod 合并后的视图），保存下来的是 `textures/myskin/body_rfaos.dds` 这样的游戏路径。你不需要关心文件实际放在哪个 mod 目录里，之后贴图打包进 BSA 也照样能用。BSA 里的贴图不会列出，请在输入框里直接填写路径并按回车。

一套皮肤通常有好几张贴图：头、身体、手，往往还有脚，男女各一份，兽人种族再各一份。每张贴图都需要自己的材质文件。想让它们使用相同的数值，可以先保存一个，再选中下一张贴图，使用**复制与分享 → 从其他材质文件复制数值...**。手绘贴图不会被复制，因为它们只对得上各自那张贴图的 UV。

## 手写材质文件

材质文件是普通的 JSON，只需要写和公用参数不同的部分。

```json
{
    "format": "CommunityShaders.SkinMaterial",
    "version": 1,
    "parameters": {
        "Roughness": 0.62,
        "SecondaryRoughness": 0.3,
        "Fuzz": 0.8
    },
    "textures": {
        "controls": "textures/myskin/femalebody_rfaos.dds",
        "wet": "textures/myskin/femalebody_wet.dds",
        "detail": "textures/myskin/pores_n.dds"
    }
}
```

全部参数名和取值范围见[参数表](advanced-skin-materials.md#parameters)。文件里可以写 `//` 注释。

文件只要有一处错误，整个文件都会被忽略，皮肤改用公用参数，不会出现“生效一半”的情况。原因会写在 Community Shaders 日志里（搜索 `[Advanced Skin]`），在皮肤编辑器里选中这张贴图时也会显示。常见原因是少了逗号、参数名拼错、数值超出范围。

在游戏外修改了材质文件或 DDS 之后，点击**重新加载皮肤资源**。

## 贴图怎么画

三张贴图都是可选的。它们必须按所属漫反射贴图的 UV 来画。

**皮肤控制图（`controls`，也叫 RFAOS）** —— 线性数据。

| 通道 | 含义                       |
| ---- | -------------------------- |
| R    | 粗糙度                     |
| G    | 绒毛倍率                   |
| B    | 环境光遮蔽；1 表示没有遮蔽 |
| A    | 高光                       |

没有这张贴图时，**第一层粗糙度**和**第二层粗糙度**直接决定两层高光，反射强度使用**反射率（F0）**。有这张贴图时，R 通道分别乘以两个 **RFAOS 粗糙度倍率**来驱动两层高光：R = 0.5、倍率为 1.3 和 0.75 时，得到 0.65 和 0.375（再叠加边缘额外粗糙度）。高光强度变为 `0.08 × A × RFAOS 高光倍率`。两种情况下都由**第二层高光强度**混合两层高光。

**细节（`detail`）** —— RGB 是可平铺的切线空间法线，比如毛孔。Alpha 是一张单独的图，按漫反射贴图的 UV 绘制：白色表示完整细节，黑色表示没有细节。把嘴唇涂黑，毛孔就不会出现在嘴唇上。修改**细节平铺**只改变毛孔的大小，不会移动你画的区域。没有细节贴图时使用公用细节贴图；**身体平铺倍率**控制头部以外的平铺。

**湿润表面（`wet`）** —— RGB 是湿润层的切线空间法线；不需要额外起伏的地方用平坦的 `(0.5, 0.5, 1)`。Alpha 控制哪里会变湿。没有这张贴图时，湿润层是平的，并且覆盖全身。

游戏原有的皮肤贴图（`_sk`）控制薄处的透光程度：白色薄，黑色厚。它和 **SSS 强度**无关，后者控制的是后处理的次表面散射。

格式：带手绘 Alpha 的贴图请用 RGBA8 或 BC7。BC5 UNORM 只能用于不带遮罩的细节法线，它存不了遮罩。请生成 mipmap，并从远处检查遮罩的边缘。

### 不借助外部工具打包通道

点击页面标题栏的工具按钮，或贴图行上的工具按钮，打开**贴图工具**窗口。选择**皮肤控制图**或**细节法线＋遮罩**。制作控制图时，为 R、G、B、A 分别选择尺寸相同的灰度图；没有选图的通道使用界面上显示的常量。源图可以来自磁盘上的任何位置。在**输出**里填写结果的游戏路径，默认建议放在当前皮肤贴图旁边。**生成并保存 DDS** 会把带 mipmap 的线性数据写到输出 mod 文件夹，可选 BC7 压缩。**用于……**会把结果指定给你正在编辑的层。输入支持 DDS、PNG、TGA、TIFF、BMP，最大 8192 × 8192，各输入的尺寸必须一致。

## 单独调整某个角色

当主角或某个随从需要和使用同一套皮肤的其他人略有不同时使用，比如更油亮、绒毛更少、有专属的细节遮罩。

1. 点击**玩家**或**控制台所选对象**，并选中一张贴图。
2. 在面包屑里点击要编辑的层：
    - **整个角色**：只能调数值，头、身体、手、脚一起生效。
    - **角色在此贴图上**：可以调数值和贴图，只对选中的贴图生效，优先级最高。
3. 调整后保存。两个角色层会一起保存在该角色的文件里。

微调会保存为该角色的一个小 JSON 文件，位于 `Data/SKSE/Plugins/CommunityShaders/AdvancedSkin/Characters`。它在所有存档中生效，作用于使用该 NPC 记录的所有角色；你可以手动编辑、分享，或随随从 mod 一起发布。[文件格式](advanced-skin-materials.md#character-files)见技术文档。在游戏外修改后，点页面标题栏的重新加载按钮。

玩家文件作用于你当前游玩的角色。想保留多套外观，可以另存副本后替换，或者使用**复制与分享 → 从其他角色文件载入...**。

如果角色不再显示某张贴图（比如主角换了种族），针对它的微调会留在列表的**有微调，当前未显示**分组里，等贴图换回来就重新生效。选中它即可编辑或清空。

**复制与分享**里还有用于分享的**另存副本...**和**打开文件夹**。针对特定贴图的设置，会在任何显示同一张贴图的地方生效。如果某个角色文件有错误，页面顶部会出现提示条，点击即可查看原因。

## 打包与检查

发布时，把每个 `.csskin.json` 放在对应的漫反射贴图旁边，连同它引用的 DDS 一起发布，散装或打进 BSA 都可以。不需要 ESP。因为材质文件就在贴图旁边、遵循相同的覆盖规则，所以覆盖你贴图的 mod 也可以为它提供自己的材质。

在编辑器里保存材质时，会记录它是为哪个版本的漫反射贴图制作的。如果之后贴图被其他 mod 替换，而生效的材质文件仍然是你的，编辑器会在选中这张贴图时给出警告，因为手绘遮罩可能已经对不上了。

请检查：脸和身体的接缝、嘴唇等排除了细节的区域、近景和远景、干燥和湿润两种光照、第一人称的手，以及至少一件露出皮肤的衣服。

## 常见问题

| 现象                             | 可能的原因                                                                |
| -------------------------------- | ------------------------------------------------------------------------- |
| 材质没有任何效果                 | 文件名和角色实际显示的漫反射贴图对不上。请对照编辑器表格里的路径。        |
| 表格显示**材质文件无效**         | JSON 有错误。选中这张贴图即可看到原因。                                   |
| 保存了，但重新加载后显示的不是它 | 有优先级更高的 mod 提供了同名文件，或者文件保存到了游戏不会加载的文件夹。 |
| 某张贴图输入没有生效             | DDS 不存在或格式不受支持；日志里有相应信息。                              |
| 表格显示**无法识别的贴图**       | 这个表面的漫反射不是普通的 DDS 文件，无法拥有材质，只能使用公用参数。     |
